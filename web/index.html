READY FOR YOUR OWN PROJECT?

Bring a task.
Bring your own key.

Install IMIKWON from the repository into a Python virtual environment. Get a Moonshot API key and configure it locally. Choose a source file and its test, then set your cost ceiling.

The command-line tool sends those files to your chosen provider. Keep personal information and confidential code out unless you have permission to share them.

Open the setup guide 
imikwon propose "Fix the bug and add tests" \
  --file src/calculator.py \
  --file tests/test_calculator.py \
  --input-ceiling 6 \
  --output-price 10 --budget 1

After installation and key setup. Replace the file paths with yours. The $6 input ceiling conservatively includes the higher cache-write rate; it is not the standard input price. Local estimates cannot guarantee the provider's bill.

CLEAR TERMS. ROOM TO IMPROVE.

What you are getting.

Is it really open-source?

Yes. IMIKWON's original code and documentation use the MIT licence, including commercial reuse. Kimi is an upstream model with separate terms. We have not verified K3.1 Pro's downloadable checkpoint and specific licence, so this release uses its documented API and distributes no model weights.

Can I use it completely free?

The software and offline demo are free. Live model calls require your own provider account and are billed by that provider. There is no IMIKWON subscription, markup or free hosted inference allowance.

How much coding can this release handle?

Bounded tasks across up to 24 selected UTF-8 files, 64 KB per file and 160 KB total context. It can create and modify files. It does not execute model-selected commands, delete files, commit or push automatically. A full browser IDE and autonomous repair loop are future work.

Has the quality been independently proven?

No. The software's local and mocked tests pass, but live Kimi inference, independent security review and comparative cost or coding-quality benchmarks remain outstanding. The repository records these limits openly.
