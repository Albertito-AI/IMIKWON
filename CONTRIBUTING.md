# Contributing to IMIKWON

Small, reproducible contributions are welcome. Open an issue describing the task, expected behaviour and actual result, or submit a pull request with a focused change and relevant tests. Do not post keys, private source, personal information or provider reasoning traces.

Run `python -m unittest discover -s tests -v` and `python -m imikwon demo`. Runtime code must remain usable with Python 3.10+ and no third-party runtime dependency unless a documented need justifies the change.

Priority work: live-provider acceptance tests; measured coding tasks with reported costs; optional exact token counting; safer isolated test execution; and an accessible local interface. Add measurements before marketing performance or savings. Preserve source scope, explicit application, cost admission control, complete Kimi assistant history and honest test status.

By contributing, you agree to license your contribution under this repository's MIT licence. Confirm that you have the necessary rights. Identify AI assistance where relevant to provenance and review. Contributions receive no promise of payment, employment or endorsement.
